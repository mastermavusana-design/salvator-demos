# salvator-demos

Preview ("mock") websites that SALVATOR ORBIS builds for prospective clients.

- One folder per business: `/<business-slug>/index.html`
- Built by Forge (Bestie agent team) and by Vusumuzi + Claude
- Photos: the business's own public photos where available, otherwise free-licence stock (Unsplash/Pexels)
- Not indexed by search engines (robots.txt + _headers). Previews are removed on request.
- Hosted on Cloudflare Pages; every push to `main` deploys automatically.
